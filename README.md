## Phần 1: Phân tích bài toán (I/O): Xác định rõ Dữ liệu đầu vào (nội dung CLB cần trình bày) và Kết quả mong đợi (file [README.md](http://README.md) render ra trang hiển thị như thế nào).
Input
- Thông tin cơ bản về CLB PTIT
- Quy trình cho người mới vào
- Danh sách nv, deadline người mới cần hoàn thành

Output
- Một file README.md hoàn chỉnh trên github đẹp mắt chi tiết và dễ nhìn
Giúp cho người mới dễ nhìn và nắm bắt được thông tin
## Đề xuất giải pháp: Mô tả ngắn gọn cách bạn tổ chức 5 phần trong file, cú pháp nào dùng cho phần nào.
- Giới thiệu: Tên CLB dùng # hoặc ##
- Danh sách ban: Giới thiệu các trưởng ban và cách liên lạc dùng []()
- Hướng dẫn gia nhập
- NV, và deadline của nhóm
- Những lưu ý quan trọng
## Thiết kế các bước: Gạch đầu dòng tuần tự các thao tác bạn sẽ làm để tạo file (không cần mô tả từng ký tự, chỉ cần mô tả logic).
- Tạo file readme.md trên github
- Tạo tiêu đề và giới thiệu qua về CLB
- Tạo bảng các ban và cách liên lạc của CLB'
- Các quy trình để tham gia CLB
- Lập danh sách nv và deadline
- Kiểm tra lại sửa lỗi và hoàn thành
